# Telegram-бот для форматирования HTML-текста

Telegram-бот позволяет быстро и удобно отформатировать html-код в удобочитаемый текст.

- [Принцип работы](#working)
- [Инструкция по установке](#installation)
- [Инструкция по получению токена](#token)
- [Инструкция по эксплуатации](#user-guide)

<h3 id="working">Принцип работы:</h3>

Telegram-бот развёртывается локально на вашем ПК. Достаточно установить программу, внести токен бота и нажать кнопку включения, после чего бот будет готов к общению и форматированию!

<h3 id="installation">Инструкция по установке:</h3>

1. Зайдите в раздел Releases;
2. Скачайте последнюю версию установочного пакета;
3. Запустите установку;
4. Укажите путь для установки;
5. Внесите токен telegram-бота (о получении токена см. инструкцию ниже);


<h3 id="token">Инструкция по получению токена бота</h3>

Токен бота (Bot token) - это уникальная последовательность символов, которая соединяет программу с интерфейсом Telegram. Токен - **секретный**. 

___Ни в коем случае не передавайте токен третьим лицам! Злоумышленник, получив токен, получит доступ к вашему боту и сможет выполнять операции от его имени!___

Как получить токен:
1. Начните диалог с `@BotFather` в telegram - праотцом всех ботов;
2. Выполните команду `/newbot`;
3. Задайте имя, описание и тег для будущего бота согласно инструкции;
4. Введите команду `/token`;
5. Скопируйте строку вида: ``` 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz123456789 ```

<h3 id="user-guide">Инструкция по эксплуатации</h3>

Рабочее окно состоит из 2 областей:

1. Меню бота;
2. Область событий.

В меню бота Вы можете управлять рабочим состоянием, а также **заменить токен**, если тот неактуален.
В области событий отображаются время и действия, которые были произведены с ботом, а также все ошибки и исключения, которые были выявлены программой. 

___В отключеном состоянии бот работать не будет!___ 

После включения перейдите в telegram, начните диалог с ботом, который был вами создан, и следуйте инструкциям.
При отправке отформатированного текста боту тот вернёт сообщение, где каждый поддерживаемый тег будет переведён в telegram-объект. **Список HTML-тегов**, которые поддерживает Telegram, **остаётся актуальным** и **не зависит от версии** установленной программы.
